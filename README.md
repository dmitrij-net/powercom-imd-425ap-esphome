# powercom-imd-425ap-esphome
Интеграция ИБП Powercom IMD-425AP в Home Assistant через ESPHome (UART протокол)

Этот проект позволяет полностью интегрировать ИБП **Powercom IMD-425AP** (серия IMPERIAL) в Home Assistant через ESP-01 (ESP8266), минуя штатный USB-мост (CY7C63723).

Устройство подключается напрямую к внутреннему UART микроконтроллера ИБП, что позволяет не только читать данные, но и удаленно управлять питанием и запускать тесты.

## ✨ Возможности
*   **Мониторинг:** Нагрузка (%), заряд АКБ (%), входное/выходное напряжение (В), частота (Гц).
*   **Статусы (Бинарные сенсоры):** Пропадание сети, низкий заряд АКБ, перегрузка, срабатывание AVR (повышение/понижение), самотест, тихий режим, Green Mode.
*   **Управление:**
    *   Включение/выключение ИБП (эмуляция кнопки через оптрон).
    *   Запуск теста батареи (программно по UART или эмуляцией кнопки).
*   **Адаптивный опрос:** ESP опрашивает ИБП каждые 2 секунды, когда он включен, и раз в 30 секунд, когда он выключен (для экономии ресурсов и чистоты логов).
*   **Защита от "дребезга":** Умная логика переключателя предотвращает ложные срабатывания при включении/выключении.

## 🛠 Аппаратная часть
*   **ИБП:** Powercom IMD-425AP (или аналогичный из серии IMPERIAL).
*   **Микроконтроллер:** ESP-01 (ESP8266).
*   **Развязка:** 3 оптрона (например, PC817, два уже имеется на плате) для линий RX, TX и кнопки питания.
*   **Питание:** DC-DC преобразователь 3.3V (ESP-01 требует до 300 мА в пике).

### ⚠️ Важные схемотехнические нюансы:
1.  **Штатный USB-мост (CY7C63723) должен быть физически отключен** от линий UART, иначе он будет создавать конфликты на шине.
2.  **Strapping-пин GPIO1 (TX):** При подключении оптрона к этому пину, ESP-01 не загрузится. Требуется установка подтягивающего резистора (номинал подбирается индивидуально, обычно > 4.7 кОм) между GPIO1 и 3.3В.

## 📡 Протокол обмена (Реверс-инжиниринг)
Протокол бинарный. Скорость UART: **1200 бод, 8N1**.

### Команды (ESP -> ИБП)
*   `0x01` — Запрос статуса (ИБП отвечает пакетом из 16 байт).
*   `0x03` — Запуск теста батареи.
*   `0x04` — ⚠️ **ОПАСНО!** Приводит к зависанию MCU ИБП. Не использовать!

### Ответ ИБП (Пакет 16 байт)
| Байт | Назначение | Примечание |
|---|---|---|
| `data[0]` | Нагрузка | Прямое значение в % |
| `data[1]` | Заряд АКБ | Прямое значение в % |
| `data[2]` | Входное напряжение | `значение * 2.0` (Вольты) |
| `data[3]` | Выходное напряжение | `значение * 2.0` (Вольты) |
| `data[4]` | Частота на входе | Прямое значение (Гц) |
| `data[5]` | Резерв | Всегда `0xFF` (?) |
| `data[6]` | Частота на выходе | Прямое значение (Гц) |
| `data[7]` | Резерв | Всегда `0x00` (?) |
| `data[8]` | Резерв | Всегда `0x00` (?) |
| `data[9]` | **Байт статусов** | Битовая маска (см. ниже) |
| `data[10]`| **Байт режимов** | Битовая маска (см. ниже) |
| `data[11]`| Константа | Всегда `0x4B` (версия ПО?) |
| `data[12]`| Константа | Всегда `0x18` (версия ПО?) |
| `data[13-15]`| Резерв | Всегда `0x00` (?) |

### 🚨 Байт 9 (Статусы / Аварии)
*   `0x01` — AC Power Lost (Нет сети)
*   `0x02` — Low Battery (Низкий заряд АКБ)
*   `0x04` — Input Voltage Low (AVR повышает)
*   `0x08` — Input Voltage High (AVR понижает)
*   `0x20` — Overload (Перегрузка)

### ⚙️ Байт 10 (Режимы работы)
*   `0x04` — Self-Test (Идет тест батареи)
*   `0x08` — Beeper Muted (Звук отключен)
*   `0x40` — Normal Mode (Green Mode отключен). Если бит `0`, ИБП работает в энергосберегающем Green Mode.

## 🎮 Управление кнопкой питания
*   **< 1 сек:** Тест батареи / Отключение звука (Mute).
*   **~2.5 сек:** Включение (активируется Green Mode).
*   **> 4 сек:** Включение (Green Mode отключается, ИБП не выключится при малой нагрузке).
*   **~3 сек (при работе):** Выключение ИБП.

## 🚀 Установка
1. Установите ESPHome.
2. Скопируйте конфигурацию из `esphome/imd-425ap.yaml` в ваш конфигуратор ESPHome.
3. Замените `!secret` переменные на ваши данные (Wi-Fi, ключи API).
4. Скомпилируйте и прошейте ESP-01.
